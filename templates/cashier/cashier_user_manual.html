Cashier User Manual

Your complete guide to using the Registry system as a Cashier. This manual covers your read-only access to financial data, report generation, and profile management.

Version 2.0 · Updated July 2026

Read-Only Access Notice

As a Cashier, you have read-only access to all financial data. You can view cheques, fund clusters, account titles, suppliers, RADAI entries, and generate reports. However, you cannot create, edit, or delete any records. Only administrators have write permissions.

Frequently Asked Questions

Common questions from cashier users

Why can't I see the "Add Cheque" button?

As a cashier, you have read-only access to financial data. The "Add Cheque" button and edit/delete actions are only visible to administrators. If you need to create a cheque record, please contact your admin.

Can I generate reports?

Yes! Cashiers can generate and export all report types. Navigate to Reports, select a report type, set your filters, and click Generate Report. You can preview on screen or export as PDF.

How do I change my password?

Go to Profile Settings from the sidebar, click the Change Password button, verify your current password in the first modal, then enter and confirm your new password in the second modal.

Can I search for cheques by payee name?

Yes. In the Cheques section, type the payee name in the search bar. The list will filter in real-time to show matching results. You can also use the status filter chips to narrow results further.

What should I do if I see incorrect data?

Since you cannot edit records, please report any data discrepancies to your system administrator. Provide the cheque number, date, and a description of the issue for faster resolution.

Does the system log my activity?

Yes. All actions including page views, searches, and report generations are logged in the audit trail. This helps maintain accountability and track system usage.
