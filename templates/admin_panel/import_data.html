File Format Requirements

Suppliers: Check Serial, Check Date, DV/Payroll No., ORS/BURS No., Responsibility Center, UACS Object Code, Payee, Nature of Payments, Gross Amount, Professional Tax, Tax (5%/3%), Tax (2%/1%), Net Amount, Fund Cluster, Remarks, Other Deductions

Fund Clusters: code, name, description, balance, is_active

RADAI: Date, Serial No., Payee, Amount, ORS/BURS No. & Responsibility Center, Nature of Payment, DV/Payroll No., UACS Object Code, Fund Cluster, Remarks

Import Rules
  • Supplier imports create a new row for each imported record
  • RADAI imports create a new row for each imported record
  • Fund cluster imports are matched by code and updated if they already exist
  • All imports are logged in the Audit Log
  • Preview is shown before final import
