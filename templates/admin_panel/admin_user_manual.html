Import Data

Bulk import records from CSV and Excel files

Import Data allows you to bulk-load records into the system from CSV or Excel (.xlsx) files, saving time on large data entries.

Import Data
Upload Excel files to import suppliers, cheques, and other transactional data

Import Process

1

Open Import Data

Navigate to Import Data from the sidebar menu. You'll see a centered Upload File card with Import Type dropdown and file picker.

2

Select Import Type

Choose the data type to import: Suppliers, Fund Clusters, or RADAI.

3

Download Template

Click Download Template (XLSX) or CSV to get the correctly formatted template with column headers.

4

Fill & Upload

Fill in the template with your data, then select the file using the file picker.

5

Review & Confirm

Preview the imported data in the modal, select the sheet (for Excel files), then click Confirm Import to finalize.

File Format Requirements

Suppliers: Check Serial, Check Date, OR Number, Series/Day, DV/Payroll No., ORS/BURS No., Responsibility Center, UACS Object Code, Payee, Nature of Payments, Gross Amount, Professional Tax, Tax (5%/3%), Tax (2%/1%), Net Amount, Other Deductions, Fund Cluster, Remarks

Fund Clusters: code, name, description, balance, is_active

RADAI: Date, Serial No., Payee, Amount, ORS/BURS No. & Responsibility Center, Nature of Payment, DV/Payroll No., UACS Object Code, Fund Cluster, Remarks

Import Rules

  • Supplier imports create a new row for each imported record
  • RADAI imports create a new row for each imported record
  • Fund cluster imports are matched by code and updated if they already exist
  • All imports are logged in the Audit Log
  • Preview is shown before final import
Data Validation The system will highlight rows with validation errors before import. Fix all errors in your file and re-upload. Duplicate records will be skipped with a warning.

Backup & Restore

Protect your data with regular backups and disaster recovery

Regular backups protect your data from loss. The system supports both automatic scheduled backups and manual backup/restore operations.

Creating a Manual Backup

1

Open Backup & Restore

Navigate to Backup & Restore from the sidebar.

2

Click "Create Backup"

Click the Create Backup button. The system will generate a complete database backup.

3

Download Backup File

Once complete, click Download to save the backup file (.sql or .zip) to your local machine.

Restoring from Backup

Caution Restoring a backup will overwrite all current data. This action is irreversible. Always create a backup of the current state before restoring.
1

Upload Backup File

In the Backup & Restore page, click Upload Backup and select your .sql or .zip backup file.

2

Confirm Restore

Review the backup details (date, size). Click Restore and confirm the warning dialog.

3

System Restart

The system will briefly restart after restore. All users will be logged out during this process.

MFA Security Setup

Enable multi-factor authentication for enhanced security

Multi-Factor Authentication (MFA) adds an extra layer of security by requiring a verification code in addition to the password during login.

Enabling MFA

1

Open MFA Setup

2

Scan QR Code

Open your authenticator app (Google Authenticator, Authy, etc.) and scan the displayed QR code.

3

Enter Verification Code

Type the 6-digit code from your authenticator app into the verification field.

4

Enable MFA

Click Enable MFA to activate multi-factor authentication for your account.
