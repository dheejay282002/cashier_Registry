1. System Overview

The Registry System is a comprehensive financial management platform designed for organizations to manage cheques, suppliers, fund clusters, RADAI entries, and generate detailed financial reports.

Cheque Management

Create, edit, print, and void cheques with full audit trail and PDF export capabilities.

Supplier Database

Maintain a comprehensive supplier registry with encrypted account details and status tracking.

Fund Clusters

Organize finances by fund cluster with balance tracking and bank account management.

RADAI Tracking

Record and manage Receipts and Disbursements Audit Information with full reporting.

Advanced Security

MFA support, device management, session control, and comprehensive audit logging.

AI Assistant

Built-in chatbot powered by multiple AI providers for instant financial data queries.

2. Getting Started

System Requirements

  • Modern web browser (Chrome, Firefox, Edge, or Safari)
  • Stable internet connection
  • Screen resolution: 1024x768 minimum

Accessing the System

1
Open your web browser Launch Chrome, Firefox, Edge, or Safari.
2
Navigate to the system URL Enter the provided URL in the address bar (e.g., http://127.0.0.1:8000 or the production URL).
3
Login Page You will be redirected to the login page. Enter your credentials to proceed.
Note: First-time users should contact the system administrator for account credentials.

3. Authentication & Login

Login Process

The system supports login using either your username or email address.

1
Enter Credentials Type your username or email in the first field, and your password in the second field.
2
Toggle Password Visibility Click the eye icon to show or hide your password as you type.
3
Click Sign In Press the Sign In button to authenticate.

Password Requirements

  • Minimum 8 characters
  • Must be changed on first login if marked as temporary by administrator

Forgot Password

If you've forgotten your password:

  1. Click the "Forgot password?" link on the login page
  2. Enter your email or username
  3. Check your email for a 6-digit verification code
  4. Enter the code and set a new password
Important: The password reset code expires in 5 minutes. If you didn't receive the code, check your spam folder or contact your administrator.

Single Device Enforcement

For security, the system allows only one active session per user. If you try to log in while already logged in on another device:

  • You will be blocked from logging in
  • The active session will be notified of the attempt
  • Contact an administrator to terminate the other session if needed

4. Multi-Factor Authentication (MFA)

MFA adds an extra layer of security by requiring a second form of verification after your password.

Supported MFA Methods

Method Description Setup
Authenticator App (TOTP) Generate codes using Google Authenticator, Authy, or similar apps Scan QR code in Profile Settings
Email OTP Receive a 6-digit code via email Enable in Profile Settings

Using MFA During Login

1
Enter Password After entering your username and password, you'll be prompted to choose an MFA method.
2
Select Method Choose between "Authenticator App" or "Email OTP" based on your enabled methods.
3
Enter Code Enter the 6-digit code from your chosen method. The system will auto-submit when 6 digits are entered.

Setting Up MFA

To enable MFA on your account:

  1. Go to Profile Settings
  2. Scroll to the MFA section
  3. Click "Setup Authenticator App" or "Enable Email OTP"
  4. Follow the on-screen instructions

6. Fund Clusters Management

Fund clusters represent different funding sources or departments within your organization.

Viewing Fund Clusters

  1. Navigate to Fund Clusters in the sidebar
  2. The list displays all fund clusters with their codes, names, and balances
  3. Active clusters are indicated by a green status badge

Creating a Fund Cluster

1
Click "Add Fund Cluster" Use the button in the Fund Clusters page header.
2
Fill in Details
  • Code: Unique identifier (e.g., "GAS", "RAO")
  • Name: Full name of the fund
  • Description: Optional description
  • Balance: Current fund balance
  • Bank Name: Associated bank
  • Account Number: Bank account number (encrypted)
3
Save Click Save to create the fund cluster.
Note: Account numbers are encrypted for security. Only authorized users can view full account details.

7. Suppliers Management

Manage your organization's supplier registry with complete contact and payment information.

Supplier Status

Status Description
Active Supplier is currently active and can receive payments
Inactive Supplier is temporarily suspended
Blacklisted Supplier is permanently banned

Adding a Supplier

  1. Navigate to Suppliers in the sidebar
  2. Click "Add Supplier"
  3. Fill in the required fields:
    • Account Name: Company or individual name
    • Account Number: Bank account (encrypted)
    • Address: Supplier address
    • TIN: Tax Identification Number
  4. Click Save

Importing Suppliers

You can import suppliers from a CSV file:

  1. Go to Import Data in the sidebar
  2. Download the import template
  3. Fill in the template with your supplier data
  4. Upload the completed file
  5. Review the preview and confirm import

Exporting Suppliers

Export your supplier list to CSV:

  1. Navigate to Suppliers
  2. Click the "Export" button
  3. The CSV file will be downloaded

8. Cheque Management

Create, manage, and track cheques with comprehensive workflow support.

Cheque Status Workflow

Status Description Next Action
Draft Cheque created but not yet submitted Edit, Delete, or Advance
Pending Cheque submitted for processing Advance or Void
Released Cheque has been issued Print, PDF
Voided Cheque has been cancelled None
Stale Cheque has expired None

Creating a Cheque

1
Navigate to Cheques → New Cheque Click "Cheques" in the sidebar, then "New Cheque".
2
Fill in Cheque Details
  • Cheque Number: Auto-generated or manually entered
  • Payee: Select from suppliers or enter custom name
  • Fund Cluster: Select the funding source
  • Amount: Enter the cheque amount
  • Date: Cheque date
  • Purpose: Description of payment
  • Bank Details: Bank name and account number
3
Save as Draft Click "Save" to create the cheque as a draft.

Advancing Cheque Status

To move a cheque to the next status:

  1. Open the cheque from the list
  2. Click "Advance Status"
  3. Confirm the action

Voiding a Cheque

Warning: Voiding a cheque is irreversible. A reason is required.
  1. Open the cheque
  2. Click "Void"
  3. Enter the void reason
  4. Confirm the action

Printing & PDF Export

For released cheques:

  • Print: Click the print icon to open the print dialog
  • PDF: Click the PDF icon to download a PDF copy

9. RADAI Entries

RADAI (Receipts and Disbursements Audit Information) tracks financial transactions with detailed records.

Adding a RADAI Entry

  1. Navigate to RADAI in the sidebar
  2. Click "Add RADAI"
  3. Fill in the required fields:
    • Account Name: Payee name
    • Amount: Transaction amount
    • Date: Transaction date
    • Nature of Collections: Description
    • Fund Cluster: Associated fund
  4. Click Save

Editing RADAI Remarks

  1. Click on the RADAI entry to view details
  2. Click "Edit Remark"
  3. Update the remark text
  4. Save changes

Exporting RADAI

Export RADAI entries to CSV for external analysis or reporting.

13. Security Features

The system includes multiple security layers to protect your data.

Lock Screen

Lock your screen when stepping away:

  • Click the Lock button in the navigation
  • Or wait for the auto-lock timeout
  • Enter your password to unlock

Device Management

Administrators can:

  • View all active device sessions
  • See device information (OS, browser, IP, location)
  • Terminate unauthorized sessions
  • Block devices from future access

Session Management

  • Only one active session per user is allowed
  • Session timeout based on system settings
  • Automatic logout after extended inactivity

Encrypted Data

Security: Sensitive data including account numbers, email addresses, and passwords are encrypted at rest.
  • Bank account numbers
  • User email addresses
  • Passwords (hashed, never stored in plain text)

Audit Logging

All significant actions are logged with:

  • User who performed the action
  • Action type and details
  • Timestamp

View audit logs in Audit Log section (Admin only).

Backup & Restore

Administrators can:

  • Create full system backups
  • Download backup files
  • Restore from previous backups

15. Troubleshooting

Common Issues

Issue Likely Cause Solution
Cannot login Wrong credentials or blocked device Check username/password; contact admin if device is blocked
MFA code not working Time sync issue or wrong code Ensure device time is correct; request new code
Session kicked message Logged in on another device This is by design for security; use one device only
Cannot create cheque Insufficient permissions Contact admin to verify your role permissions
Report not generating No data for selected period Try a different date range
Email not sending SMTP configuration issue Check email settings; use "Send Test Email"
Chatbot not responding API key invalid or service down Check API key; verify provider status

Contact Support

For issues not resolved above:

  • Contact your system administrator
  • Provide your username and a description of the issue
  • Include screenshots if possible
Tip: Check the Audit Log for any recent changes that might have affected your access.
